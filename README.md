# Oceanic Tools

This repository contains two independently run applications:

- `frontend/` — Next.js web application.
- `backend/` — Express API, Prisma schema/migrations, and background worker.

Each application has its own `package.json`, lockfile, and environment configuration. Keep credentials in `backend/.env`; do not commit environment files.

See `frontend/README.md` and `backend/README.md` for app-specific setup and run instructions.
